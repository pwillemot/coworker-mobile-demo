# Agentforce Coworker — mobile demo

Two-screen mobile prototype: the Coworker **Daily Brief** digest and a Salesforce-mobile-style **Seller Home**.
Installable as a "Coworker" Home Screen app (Safari → Share → Add to Home Screen).

- `#brief` / `#home` — start screen
- `?name=Patrice` — replace the seller name (remembered on the device)
- `?nosplash` — skip the launch screen
- Swipe left/right (phone) or ←/→ (laptop) to move between screens

Static demo with fictional data (United Oil & Gas / Rekha). Not connected to an org.
